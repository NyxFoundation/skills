# 声に出す文の書き方

台本が「AI が書いた」と言われるとき、指摘されているのはほぼ次の 8 つのどれか。
**内容ではなく、文の作りの問題。**

---

## AI 臭の 8 つの兆候

### 1. 読み上げ文に太字が入っている

**声に太字はない。**書き物の体裁のまま喋らせようとしている証拠。
強調したい語は、**その語の前に間を置く**か、**短い文にして独立させる**。

```
✗ > このセッションでは、その理由を**社内で成果を測って承認を通す工程のほう**に置いて 40 分を使います。
✓ > 今日はそれを、モデルの性能の話にはしません。
  > 社内で、成果を測って、承認を通す。その工程のほうが追いついていない。
```

### 2. 一文が長く、全部が完結した宣言文

息継ぎができない。**読点で切れる長さにする。**断片も使う。

```
✗ > エージェントが代わりに買い物をする仕組みは 2026 年前半にほぼ出そろいましたが、揃っていないのは買ったあとの後始末です。
✓ > 買うところまでは、動いています。
  > 揃っていないのは、そのあとです。
  > 返す。取り消す。費用を誰が負うのか。
```

### 3. 相槌がない

質問 → 答え → 次の質問、と無言でつながっている。**人間は必ず反応する。**

```
✓ > なるほど。……いま、けっこう重い話が出ました。
✓ > ……止める基準が、ちゃんと数字で言える。これは重要です。
✓ > そこは意外です。
```

### 4. 客席に一度も話しかけていない

「みなさん」が一度も出てこない台本は、司会の台本ではない。
**呼びかけ・挙手・拍手の 3 つを必ず入れる。**

### 5. 同じ型が全セッションで繰り返される

「持ち帰りは 3 つです」が 6 本すべてに出てくると、様式に見える。
**回によって締め方を変える。**数を挙げる回、問いで終える回、次に渡す回。

### 6. 接続詞が全部そろっている

「そして」「ただし」「したがって」が毎文に付く。話し言葉は接続詞を落とす。

```
✗ > そして、次に、承認の話をします。したがって、ここが重要になります。
✓ > 次は承認の話です。ここがいちばん割れます。
```

### 7. ぼかしが多い

「〜かもしれません」「〜と思われます」「一般的には」。**司会は言い切る。**
言い切れないことは言わない。

### 8. 名前を呼んでいない

スライドがない会場では、**誰が話しているか客席には分からない。**
フリのたびに名前を呼ぶ。「◯◯さんに伺います」。

## 書くときの手順

1. **まず内容を箇条書きで書く**（これは AI が得意）
2. **声に出して読む。**息が続かない箇所で切る
3. **太字を全部外す。**外して意味が落ちるなら、文の作りが悪い
4. **相槌と呼びかけを足す**
5. **`assets/spoken_check.py` にかける**

3 を飛ばすと、必ず太字が残る。**太字は書き手が自分に向けて付けた印**で、
読み手（＝喋る人）には要らない。

---

## 間の書き方

台本に間を書く。書かないと、全部同じ速さで読まれる。

```
（見渡す）
（ほとんど挙がらない想定）
（一拍）
（間を取る。ここで客席が静かになる）
```

数字を言ったあとは必ず一拍。**客席が計算に追いつかない。**

```
> これは、9 万 9 千円の注文を 6 本出されたら、抜けます。
> 1 本ずつ見れば、全部ルールの中です。合計は、59 万 4 千円。
（間を取る）
> お三方に伺います。これを止める仕組みは、いまありますか。
```

## 字幕が出るときの追加規則

- **言い直さない。**「えー、つまり、いや」で字幕が崩れる。言い切ってから次へ
- **1 文に論点を 3 つ詰めない。**表示量が追いつかない。文を割る
- **A・B・C を使う。**「多段の委任」は音でも字幕でも入りにくい。
  「A さんが B に渡し、B が C に渡した」なら一度で読める
- 内輪語は初出で 1 語添える。「板」→「取引板」、「MCP」→「AI が外部の道具を呼び出す規格」

---

## 英語セッションでも同じ

bridge は英語でも必須。日本語話者が客席の半分以上いるなら、
**1 文で言い直すと字幕が追いつく。**

```
> So — today, the smallest unit you can take back is the session. Not the individual action.
> Paying is solved. Un-paying is not.
```

挙手も言語に関係なく効く。

```
> Quick show of hands. How many of you have an AI agent holding a key right now?
（look around）
> Now keep your hand up if you know exactly how to take that away. Today. In one action.
（most hands drop）
```

**モデレーターが非母語話者なら、台本は叩き台として渡す。**
本人の言い回しに直してもらう前提で書く。直させないと、本人が読みにくい文を無理に読む。
