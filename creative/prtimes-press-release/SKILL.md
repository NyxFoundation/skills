# PR TIMES バズるプレスリリース作成

記者に**数秒で拾われ**、SNSで**共有される**日本語プレスリリースを設計・執筆するスキル。
「わかりやすい紹介文」ではなく、**記事化されニュースとして拡散する報道素材**を作る。

> 淡々とした技術PR（誇張排除・宣伝臭ゼロの事実列挙）が欲しいときは
> **pr-drafting-workflow** を使う。こちらは**バズ＝記事化＋拡散**を最大化する攻めの原稿。

## 関連スキル
- **narrative-heat-engineering (NHE)** — 中心命題・敵（構造）・伏線回収・熱量曲線の形を先に決める。
- **emotion-curve-feedback** — 書いた後、読者ペルソナ（記者／当事者読者）で感情曲線を診断し谷を直す。
- **notion-databases** — 最終ステップの Notion 保存 API 手順。DB ID は `docs/nyx-directory.md`。

サイクル: NHE で骨子 → 本スキルの型で執筆 → emotion-curve-feedback で診断 → 直す → Notion 保存。

## ワークフロー

### Step 1 — 素材ヒアリング & ニュースバリュー設計
題材（launch / 事業 / 調査 / 提携 / イベント）を受け取り、**「なぜ今・なぜこの主体が言うのか」**に答えられるか確認。答えられなければ、下の7レバーからニュース性を**製造**する。

**ニュースバリュー7レバー（最低2つを意図的に仕込む）**

| レバー | 製造法 |
|---|---|
| 新規性 | 範囲を限定して「◯◯分野で初」を作る（全国が無理なら地域/業界/属性で限定） |
| 社会性 | 取組を「人手不足/高齢化/地方創生/物価高/生成AI」の解決として再フレーム |
| 時事・季節性 | 法改正・記念日・トレンド・季節に配信を合わせ、時事ワードをタイトル前半へ |
| 独自性 | 自社固有の歴史・顧客層・地域から「ニッチNo.1」を定義 |
| 意外性 | 社内の当たり前を外部視点で見直し、逆説・ギャップを前面に |
| 影響の大きさ | 利用者数・市場規模・削減量を**定量化** |
| 人間性・物語性 | 創業者の動機・当事者の声・試行錯誤を引用で挿入 |

**フック製造の定石**: ①自社データで**独自調査リリース**を作る（第三者性＋数字が自動で生まれる）②時事カレンダーに便乗 ③**限定条件で「初」**を成立 ④協業で影響規模を拡大。

### Step 2 — タイトル（見出し）を8テンプレから作る

**鉄則**
- **主タイトル30文字以内**（記者の第一接触点＝メール件名幅）。サブタイトルも別途30字以内。3行にしない。
- **重要キーワード・時事ワードは前半**（記者はキーワード検索で探す）。
- **数字を必ず入れる**（「たくさん」→「1,200人」「従来比2.4倍」「最大30%削減」）。
- **固有名詞を入れる**（地名・企業・製品・提携先）。
- **「日本初/業界初/世界一」は根拠付きのみ** — 条件を限定し「（自社調べ／◯◯分野において）」を添える。

| # | 型 | テンプレート |
|---|---|---|
| 1 | 数字×成果 | `[製品/施策]で[指標]を[数字]%削減／[数字]倍に、[技術/方法]で実現` |
| 2 | 初（権威づけ） | `[分野]で[国内/業界]初※、[新規性の具体]を[日付]提供開始（※[条件]、自社調べ）` |
| 3 | 時事・社会性 | `[社会課題:人手不足/物価高/生成AI等]に対応、[製品]を[対象]向けに提供開始` |
| 4 | 固有名詞×地域 | `[企業]、[地名]で[具体の取組]を[日付]開始 — [対象]の[課題]解決へ` |
| 5 | 調査データ（第三者性） | `[対象N=数字]調査、[意外な発見:◯%が△△]と判明 — [企業]が実態を公開` |
| 6 | 意外性・逆説 | `[常識]と思われた[X]、実は[意外な事実] — [企業]が[製品/調査]で示す` |
| 7 | 提携・共同 | `[A社]×[B社]、[領域]で協業 — [規模]の[課題]に挑む` |
| 8 | 当事者性×物語 | `[属性:元看護師/イクメン等]が作る[製品]、[背景/想い]から誕生し[日付]発売` |

必ず**3案以上**出し、最も強い1本を本命に。

### Step 3 — 本文（逆三角形 = 掲載率が上がる並び順）

1. **タイトル / サブタイトル**（Step 2）
2. **リード文** — 最重要。**5W1H（+How much）を1〜3文・250〜300字（最大400字）**に凝縮。「見出し＋リードだけで記事が書ける」密度に。
   型: `[企業]は、[製品/施策]を[日付]から[提供/開始]。[社会背景/課題]を解決するため[目的]に開発。[数字の要点]。`
3. **本文（逆三角形）** — 結論→重要事実→詳細→背景の降順。各段落に事実＋数字。冒頭で切られても要点が残る。
4. **サブ見出し** — 段落ごとに要約小見出し。流し読みで全体像が掴める。
5. **引用コメント（1〜3文・400字未満）** — 代表/開発者/利用者の声で**人間性（共感）**を注入。肩書き＋氏名を「」で明示。
   型: `「[課題への問題意識]。[想い/決意]。[今後の展望]」（[役職]・[氏名]）`
6. **画像・図表の指示** — メインビジュアル＋データ図（各1点は単体で意味が伝わること）。図があると記事化率が上がる。図が要るなら **editorial-figures** スキルで生成。
7. **ボイラープレート（会社概要）** — 社名/事業/設立/所在地/代表/URL。末尾固定。
8. **問い合わせ先** — 担当者名（個人名だと反応率↑）・電話・メール。

### Step 4 — 拡散する感情トリガーを1つ立てる
タイトルとリードに、次のどれか1つを明確に。**煽らず**、事実と数字で驚きを作り、感情は引用・ストーリーで自然に載せる（SNSは作為性を嫌う）。
- **共感（あるある）** ／ **驚き（意外性・データ）** ／ **憤り・課題提起** ／ **憧れ・理想** ／ **当事者性（「あなたの話です」）** ／ **物語性（逆境→挑戦→成果）**

### Step 5 — emotion-curve-feedback で自己診断
記者ペルソナ＋当事者読者ペルソナで、タイトル→リード→本文→引用→CTA を1区間ずつ感情スコア化。**谷（冷める箇所）**と**着地の弱さ**を直す。特にリードの熱量と引用の当事者性を点検。

### Step 6 — 配信メカニクスを添える（原稿と一緒に納品）
- **配信時間**: 火〜木の**10〜11時**（ピーク約30%）または**14〜15時**。午前有利。金曜午後・土日は避ける。
- **画像**: 3〜5点以上・幅600px以上、メイン＋データ図。
- **タグ**: 一般名詞で最大10個、時事ワードを含める。カテゴリは内容に最も近いものを正確に。
- **SNS導線**: 配信と同時に自社SNSでも投稿（記者がSNS経由で早期捕捉）。

### Step 7 —（ゴール）Notion Scrapbox DB に PRテンプレで保存
下記「Notion 保存」に従い新規ページを作成。作成 URL をユーザーに返して完了。

## 掲載を殺すミス（チェックリスト）
- [ ] 主観語（すごい/画期的/驚きの/好評/圧倒的）→ 全削除、数字＋固有名詞に置換
- [ ] 数字なし → 各主張に数字を1つ以上
- [ ] 引用なし → 代表/開発者コメントを追加
- [ ] 専門用語の羅列 → 中学生でも分かる語に（初出の専門語は括弧で一言説明）
- [ ] 無根拠の「業界初/世界一」→ 条件・出典を付記
- [ ] 口語調（!!／〜しちゃう）→ 公式文書トーン
- [ ] 1リリース複数テーマ → 1本1テーマに分割
- [ ] 画像・図なし → メイン＋図表を最低限

## 参考実例（構造）
- 独自調査: 「リモート勤務者1,200人調査、68%が『雑談不足』に課題 — ◯◯社が実態を公開」→ N数と%でニュース性＋信頼性、社会課題接続、宣伝語ゼロ。
- 限定「初」×時事: 「生成AIで献立提案、甲府市の学校給食に県内初※導入 — 栄養士作業を最大40%削減（※自社調べ）」→ 「県内初」を条件限定で正当化＋時事ワード前半＋40%。
- 当事者×物語: 「元看護師が開発、夜勤者向け薬膳茶8種を発売」＋監修者の当事者コメント → 共感と物語性で自分ごと化。

## Notion 保存（ゴール）— Scrapbox DB に PRテンプレで

このスキルの**成果物は必ず** Notion Scrapbox DB に新規ページとして保存する（完了条件）。
API 手順・ブロック追記の gotcha は **notion-databases** スキル、Scrapbox DB ID は **docs/nyx-directory.md** の「Scrapbox DB」を参照（ハードコードしない）。認証は `~/.config/notion/api_key` または `notion` MCP。

**プロパティ**
- `Name`（title）= `[PR原稿] <案件名> / PR TIMES`
- `Tag`（multi_select）= `["PR原稿", "PRTimes", "<案件名>"]`

**本文ブロック（この順）**
1. **callout(💡)** — 一言サマリ＋狙う感情（例:「驚き→当事者化→行動」）＋仕込んだニュースバリュー2つ
2. **H2 タイトル案** — 本命＋別案（Step 2 の3案）
3. **H2 本文（本命）** — リード〜ボイラープレート〜問い合わせまで、そのまま配信できる完成形。段落・小見出し・引用は Notion ブロック（見出し/段落）で構造化（1つの巨大テキストにしない）
4. **H2 配信メモ** — 推奨配信時間帯・タグ候補・画像点数/図の指示・SNS導線
5. **H2 バズ設計メモ** — フック／感情曲線の山と谷／当事者性の作り方
6. **H2 参考・出典**

> Notion API は1回のページ作成で**100ブロック上限**。超える場合は分割し `PATCH /v1/blocks/{id}/children` で追記。MCP ツール優先、失敗時のみ curl。保存後、作成ページ URL を返す。
