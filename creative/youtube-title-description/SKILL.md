# バズる YouTube タイトル＋概要欄 作成

**CTR（クリック率）×平均視聴時間**を最大化するタイトルと概要欄を設計・執筆するスキル。
釣りタイトルの「期待外れ」で視聴維持と満足度が崩れると逆に露出が落ちる（2025年以降強化）ため、
**守れる約束で好奇心をヒート**させる。

## 関連スキル
- **narrative-heat-engineering (NHE)** — 動画の中心の約束（1本＝1つ）と伏線を先に決める。
- **emotion-curve-feedback** — タイトル案を視聴者ペルソナで比較・診断し、最も熱いが破綻しない案を選ぶ。
- **notion-databases** — 最終ステップの Notion 保存。DB ID は `docs/nyx-directory.md`。

## 設計原則：YouTube のランク（2024–2026）
- **2段階ファネル**: ①タイトル＋サムネの「パッケージ」で **CTR** が決まる ②クリック後、**平均視聴時間/視聴維持率＋満足度**で配信量が決まる。タイトルの仕事は①＋「正確な期待設定」で②を壊さないこと。
- **CTR目安**: 平均4〜6%、**7%以上で強い**、4%未満で失速。最初の約1,000インプレ/24hが基準。
- **維持ゲート**: 50%以上視聴で Browse/Suggested に強く押される。
- **2025–26の転換**: 満足度（視聴後の1〜5★）がランクに影響。「4分間“愛されて見られる”＞8分間“我慢して見られる”」。だから**釣りの期待外れは能動的にマイナス**。
- **3つの面**: 検索＝キーワード完全一致を前半に／Suggested・Browse＝好奇心と感情で隣接動画に勝つ／Shorts＝最初の2秒。**1本のタイトルで「キーワード前半＋感情フック」を両立**させる。

## ワークフロー

### Step 1 — タイトルを型から作る（3案以上→比較）
**長さ**: EN 40〜60字（最初の約40字にペイロード）、**JP 28〜32字（キーワード＋フックを冒頭10〜13字に）**。数字は算用数字。ALL CAPS 不可、Title Case（EN）。

| # | 型 | テンプレ | 例 |
|---|---|---|---|
| 1 | 数字/リスト | `[#]個の[もの]が[成果]` | `7 Rust Mistakes That Silently Kill Performance` |
| 2 | 好奇心ギャップ | `[意外な結果]を生んだ[X]の[コツ]` | `The One Prompt Trick That Made GPT 3x Smarter` |
| 3 | Xを Yなしで | `[目標]を[面倒/前提]なしで` | `How to Run LLMs Locally Without a GPU` |
| 4 | 変化・結果 | `[期間]で[結果]した方法` | `9分→40秒に短縮したビルド設定` |
| 5 | 警告・否定 | `[X]は今すぐやめろ（[悪影響]）` | `Stop Using useEffect Like This (It's Leaking Memory)` |
| 6 | 権威/専門家に聞いた | `[専門家]に[問い]を聞いた` | `I Asked a Google Engineer How Search Really Ranks` |
| 7 | vs/比較 | `[A] vs [B]：[年]で[勝つ]のは？` | `Rust vs Go in 2026: Which Should You Learn?` |
| 8 | 誰も教えてくれない | `誰も教えてくれない[X]` | `The ZK-Proof Math Nobody Explains Simply` |
| 9 | 〜してみた/体験 | `[期間][X]して分かった[落とし穴]` | `3週間Rust書いて分かった落とし穴` |
| 10 | 年＋今 | `[年]の[X]（今効くやり方）` | `The Best RAG Setup in 2026 (What Actually Works)` |
| 11 | 疑問/本当に？ | `[X]は本当に[Y]なのか` | `Is Formal Verification Actually Worth It?` |
| 12 | 簡単/速攻 | `[複雑な話]を[N分/図解]で` | `ゼロ知識証明を3分で理解する` |

**JPフック語（冒頭に置く）**: 【暴露】【保存版】【完全版】【2026年最新】／〜してみた／〜の落とし穴／誰も教えてくれない〜／実は〜／〜は今すぐやめろ／3分でわかる〜／プロが〜。
**規則**: 感情トリガーは**1つだけ**（積み重ねると釣り判定）。キーワードは冒頭に前出し。

### Step 2 — ヒートさせる（が、外さない）
- **具体性＞誇張**。実数・固有ツール名・具体的な賭け金（stakes）は、信頼と CTR を同時に上げる。
- 好奇心ギャップ＝**主題は名指し、答えを伏せる**。「5万ドルを失ったバグ」（具体・回収可能）○／「衝撃の結果が…」（曖昧・罰される）×。
- **約束は本編の最初の30〜60秒で必ず回収**。満足度がランクを左右する今、回収できない約束は禁止。
- 2025+の「悪質クリックベイト」強化: タイトル/サムネが本編と乖離すると動画削除もあり得る。出さない結果を約束しない。

### Step 3 — サムネとの分業（テキスト側の指針）
- タイトルとサムネは**重複させない**。サムネ＝感情・被写体・大きな結果（顔・1〜3語）。**タイトル＝画像に出せない具体（数字・仕組み・stakes・「〜なしで」・期間）**。
- サムネが「$100,000」なら、タイトルは「I made $100k」ではなく「…そして3日で全て失った」。**訴求軸は1つに揃える**（軸がズレると両方良くても CTR が落ちる）。

### Step 4 — 概要欄を組む（テンプレ）
**最初の1〜2行（約100〜150字）だけが「もっと見る」前に表示＆検索で重み**。主要キーワード＋刺さる価値提案を置く（「チャンネルへようこそ」で浪費しない）。本文200〜500語、キーワードは自然に2〜3回。

```
[1行目 — キーワード前出しフック：約束＋主要キーワードを再掲]
[2行目 — 得られる成果（この2行が“折り返し上”）]

この動画で分かること：[2〜3文の要約。主要＋副次キーワードを自然に]

▼ 内容
・[セクション1の便益]
・[セクション2の便益]
・[セクション3の便益]

⏱ チャプター
0:00 [フック/導入]
0:45 [セクション1]
3:20 [セクション2]
…

🔗 リンク
- [主要リソース/repo/論文]
- ▶ 次に見る：[自チャンネルの関連動画]   ← セッション時間を伸ばす

👇 [登録CTA] ｜ SNS：[X] [GitHub] [サイト]

#キーワード1 #キーワード2 #キーワード3   （先頭3つ＝上位KW、タイトル上に表示）
```
- **チャプターは 0:00 開始**・3つ以上・各10秒以上（平均視聴時間↑ 約+11%、検索の Key Moments に露出）。
- **ハッシュタグは3〜5個**（先頭3つがタイトル上に表示＝最重要KW）。多用は spam 判定。
- 登録・SNSは価値提示の**後**（下部）。タグ欄は5分以内（誤記/別名/多言語程度、ランクへの寄与は小）。

### Step 5 — 検索意図でワードを合わせる
情報型→「[X]の仕組み/解説」、How-to→「[タスク]のやり方」、比較→「[A] vs [B]」、トラブル→エラー文をそのまま。一致フレーズを**タイトル冒頭20字**と**概要欄1行目**に。

### Step 6 — emotion-curve-feedback で案を選ぶ
タイトル3案を視聴者ペルソナで「クリック衝動／期待の高さ／裏切られなさ（回収可能性）」で採点。**最も熱いが破綻しない案**を本命に。サムネ側の一言も1案添える。

### Step 7 —（ゴール）Notion Scrapbox DB に保存

## やってはいけない
- クリックベイトの期待外れ（維持・満足度が崩壊→抑制、削除リスク）／タイトル・概要のキーワード詰め込み
- ALL CAPS・過剰な!!!／???／曖昧ミステリー（「衝撃の結果が…」主題不明）
- 価値を約40字（EN）/13字（JP）より後ろ、または概要「折り返し」下に埋める／タイトルとサムネの重複／ハッシュタグ5個超

## 実例（構造）
- EN How-to: `Run LLMs Locally Without a GPU (Full Setup in 8 Min)` ＋概要1行目でキーワード再掲、2行目で成果明示。
- JP 教育: `ゼロ知識証明を3分で理解する｜図解でわかる仕組み` ＋「数式なしの図解で3分」。
- JP 体験: `誰も教えてくれないRust入門｜3週間書いて分かった落とし穴` ＋2行目で対象視聴者を名指し（自分事化）。

## Notion 保存（ゴール）— Scrapbox DB に PRテンプレで

このスキルの**成果物は必ず** Notion Scrapbox DB に新規ページとして保存する（完了条件）。
API 手順・ブロック追記の gotcha は **notion-databases** スキル、Scrapbox DB ID は **docs/nyx-directory.md** の「Scrapbox DB」を参照（ハードコードしない）。認証は `~/.config/notion/api_key` または `notion` MCP。

**プロパティ**
- `Name`（title）= `[PR原稿] <動画名> / YouTube`
- `Tag`（multi_select）= `["PR原稿", "YouTube", "<案件名>"]`

**本文ブロック（この順）**
1. **callout(💡)** — 一言サマリ＋狙う感情トリガー1つ＋サムネの一言案
2. **H2 タイトル案** — 本命＋別案2つ（Step 1）と選定理由（Step 6 の採点）
3. **H2 概要欄（本命）** — Step 4 テンプレを埋めた完成形（チャプター・リンク・ハッシュタグ含む）
4. **H2 バズ設計メモ** — フックの型／回収ポイント（何秒で約束を返すか）／サムネ分業／検索キーワード
5. **H2 参考・出典**

> Notion API は1回のページ作成で**100ブロック上限**。超えたら分割し `PATCH /v1/blocks/{id}/children` で追記。MCP 優先、失敗時 curl。保存後、作成ページ URL を返す。
