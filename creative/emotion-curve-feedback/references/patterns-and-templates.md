# Emotion Curve Feedback — 診断パターン・ペルソナ型・テンプレート

## 1. よく出る診断パターン

| パターン名 | 曲線の特徴 | 意味 | 優先処方 |
|---|---|---|---|
| **モノトーン** | 全セクションでほぼ同じスコア | 感情刺激が弱い | 強いフック/谷/着地を作る |
| **波型** | 上下が激しい | 興味を引くが信頼感が不安定 | 谷を浅くする、根拠を増やす |
| **下降型** | 序盤高→終盤低 | 後半で期待を裏切る構造 | 後半の価値提示を再構成 |
| **上昇型** | 序盤低→終盤高 | 改善ストーリーだが序盤脱落リスク | 導入のフック強化 |
| **V字回復** | 深い谷から急回復 | 衝撃的だが回復力の証 | 谷の原因を根絶、回復を確実に |
| **逆V字** | 高揚後に急落 | 約束過多・期待ハズレ | 期待管理、実態との整合 |
| **クロス（交差）** | 複数ペルソナの曲線が交差 | 同じ情報が異なる価値に変わる | ペルソナ別に情報を再配分 |

| **ツイート・告知文** | 業界初心者 | 同業者・情報通 | 投資家・経営層 | 一般読者 |

## 7. NixOS matplotlib 日本語フォント問題

### 症状
```
RuntimeError: Can not load face (SFNT font table missing; error code 0x8e)
findfont: Font family 'Noto Sans CJK JP' not found.
```

### 原因
NixOSの `NotoSansCJK-VF.otf.ttc` は **Variable Font（VF）** であり、matplotlibのFT2Fontが直接読めない。

### 誤った対応（避ける）
```python
# ❌ これはクラッシュする
prop = fm.FontProperties(fname='/run/current-system/sw/share/fonts/opentype/noto-cjk/NotoSansCJK-VF.otf.ttc')
plt.rcParams['font.family'] = prop.get_name()
```

### 正しい対応
```python
# ✅ 名前リストでフォールバック
plt.rcParams['font.family'] = [
    'Noto Sans CJK JP',
    'Noto Serif CJK JP',
    'Noto Sans CJK SC',
    'Hiragino Sans',
    'Yu Gothic',
    'Meiryo',
    'DejaVu Sans',
    'sans-serif'
]
# キャッシュリフレッシュ（新規フォント認識）
fm._load_fontmanager(try_read_cache=False)
```

### 検証
```bash
fc-list :lang=ja | head -10
```
